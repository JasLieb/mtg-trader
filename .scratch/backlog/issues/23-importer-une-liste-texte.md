# 23: Importer une liste de cartes au format texte

**Status:** needs-triage
**Category:** enhancement
**Blocked by:** None (can start immediately)

_Rédigé par IA le 2026-10-16 ; idée de fonctionnalité à discuter au triage._

**Constat :** les cartes s'ajoutent une par une, avec la recherche. Les joueurs ont pourtant souvent leurs listes sous forme de texte, comme « 4 Lightning Bolt » ou un export de site de decks.

- [ ] Je colle une liste au format texte dans une wantlist ou dans mes doubles, et les cartes reconnues sont ajoutées.
- [ ] Les lignes non reconnues me sont signalées.
- [ ] Les noms sont résolus par le client auprès de Scryfall, sans nouvelle table côté serveur.
